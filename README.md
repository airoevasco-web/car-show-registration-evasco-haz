# Car Show Registration System

## Project Description

The Car Show Registration System is a web-based application for managing car show participant registrations. It allows users to submit registration information and helps the organizers manage participant records, registration types, fees, payments, and registration status.

## How to Run the Backend

1. Open the project folder in PowerShell.
2. Navigate to the backend folder:

   `cd backend`

3. Restore the packages:

   `dotnet restore`

4. Run the API:

   `dotnet run --project Api`

5. Check the terminal for the local API address.

## How to Run the Frontend

1. Open another terminal.
2. Navigate to the frontend folder:

   `cd frontend`

3. Install dependencies:

   `npm install`

4. Start the React application:

   `npm run dev`

*The frontend commands will be usable once the Frontend Developer adds the React application.*
